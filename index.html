设置（只做一次）

需要一个只对 lifehub-data 有写权限的 GitHub 令牌。它只存在这台手机的浏览器里，不会发给任何第三方。

  1. 手机浏览器打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便写；Expiration 选 90 天
  3. Repository access → Only select repositories → 勾 lifehub-data
  4. Permissions → Repository permissions → Contents 选 Read and write
  5. Generate token，把 github_pat_… 整段复制过来贴上面
